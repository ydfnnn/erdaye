## 更新规则
每次收到案例图，先记录来源、编号、可见事实与推断，再分析 A 数据逻辑、B 统计图形、C 视觉编码、D 信息架构、E 视觉叙事；将案例及图片归入 02，01 仅保留文字与相对链接。跨类型案例可多重关联，不重复保存图片。新增证据后修订原则、适用条件与反例，记录版本和变更原因。无图或来源不明时明确标记，不虚构观察。
