# 信息图形知识库 · Information Graphics Taxonomy

本仓库以**五种组织逻辑**建立信息图形的基础类型学，并通过实际案例不断修订数据、视觉和叙事方法。

## 唯一的基础类型学：五种组织逻辑

| 基础类型 | 核心信息关系 | 定义文档 |
|---|---|---|
| 编年型 Chronologically / Sequentially | 顺序与进程 | [01 编年型](./01-信息图形数据逻辑/01-编年型信息图形概念定义.md) |
| 层级型 Hierarchically | 等级、主次、包含与从属 | [02 层级型](./01-信息图形数据逻辑/02-层级型信息图形概念定义.md) |
| 编目型 Categorically | 对象的类别归属及分组 | [03 编目型](./01-信息图形数据逻辑/03-编目型信息图形概念定义.md) |
| 字母表型 Alphabetically / Index-based | 依检索键排列的索引 | [04 字母表型](./01-信息图形数据逻辑/04-字母表型信息图形概念定义.md) |
| 地理图型 Geographically | 位置、区域、距离与空间联系 | [05 地理图型](./01-信息图形数据逻辑/05-地理图形信息图形概念定义.md) |

**分类规则：五类是本项目唯一的基础类型学框架。** 每一件纳入案例库的信息图形，必须根据**主导的数据/信息组织关系**确定一个主归属，且只能从上述五类中选择。作品可以借用其他组织逻辑作为局部辅助，但不因此产生“第六种基础类型”。

## 02 是表现形式与市场应用的索引，不是第二套基础类型学

[02-信息图形类型案例](./02-信息图形类型案例/README.md) 用于按常见产品形式、应用情境和客户语言检索：
- [混合型信息图形 Mixed Charts](./02-信息图形类型案例/01-混合型-Mixed-Charts/00-标签说明.md)：统计图形＋可视符号＋情境化视觉叙事。
- [文字型/列表型 Informational / List Infographics](./02-信息图形类型案例/02-文字型列表型-Informational-List/00-标签说明.md)：说明、清单、步骤或知识点的可视化组织。
- [时间轴型 Timeline Infographics](./02-信息图形类型案例/03-时间轴型-Timeline/00-标签说明.md)：可读的时间或阶段序列。

**同一个市场化形式，可属于不同的基础类型；每个案例先判五类归属，再记录形式标签。** 例如“混合型”既可能组织类别比较，也可能组织区域分布；“时间轴型”通常归编年型；“文字列表型”不自动等于编目型。

## 五个研究维度

01 中五份文件统一回答：**A 数据本质逻辑、B 统计图形及计算、C 视觉编码、D 数据/信息架构、E 视觉叙事架构**。提供最小数据表、分类边界、编码约束与 02 案例链接。**01 不保存案例图片**；图片、来源、观察证据与逐图记录仅在 02 留档。

## 案例驱动的修订机制

按照 [案例录入与知识回写规范](./02-信息图形类型案例/案例录入与知识回写规范.md) 增补实例：**原图核验 → 数据关系归类 → 五维观察 → 表现形式标注 → 规律比对 → 修订 01 定义与 02 方法**。案例未核验前，禁止编造数据、来源、图形细节或实际案例结论。

## 2026-11-20｜案例入库增补规则（V3）

在既有“01 五类唯一主归属 → 02 市场表现标签 → 五维分析”的基础上，**每件案例必须有可复核的基础数据集文件**（首选 UTF-8 CSV）与字段说明：一行一个最小记录单元、一列一个原子字段、每个单元格只存一个值；金额/单位/时间口径不得混成不可计算的字符串。无法从原图辨识的坐标与数值不得编造；明确标注转录数据、计算数据、缺失源数据。基础数据与 `分析.md` 同 CASE 归档，且同步更新 01 理论、02 标签和案例索引。完整规范见 [案例录入与知识回写规范 V3](./02-信息图形类型案例/案例录入与知识回写规范.md)。

**公开版权边界**：第三方作品无转存权限时，允许用 `原图来源.md` 引用作者/出版方官方图片；必须标明“仅外链，仓库未存原图文件”，不冒充独立图片已归档。
