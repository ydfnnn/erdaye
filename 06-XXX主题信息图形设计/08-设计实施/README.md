# 08｜设计实施

目标：将已确认的数据、叙事和视觉编码实施成可展示与可复核的信息图形作品。

## 工作顺序

1. [01-草图与低保真](./01-草图与低保真/)：纸面草图、线框、信息架构图、初始构图与视觉验证。
2. [02-设计迭代](./02-设计迭代/)：高保真设计、文字/图像/符号精修、适配不同载体、反复审查与版本记录。
3. [03-最终交付](./03-最终交付/)：最终成品、可编辑源文件（若有）、使用说明、图例与来源说明。

## 最终检查

- 叙事命题是否明确？阶段、分类和标签是否相互一致？
- 数据是否可溯源且满足“一行一记录、一列一字段、一格一值”？
- 点线面体、色彩、图形、图像与字体是否准确表达对应信息？
- 图例、统计口径、单位、地图坐标、标签与文本是否可读？
- 设计表达是否形成独特的视觉系统，避免堆砌不相关图形？
- 原图、摄影及引用素材是否满足合法使用和署名要求？

本阶段不预设用户所需的具体尺寸、格式、软件或印刷标准，按实际选题确定。
