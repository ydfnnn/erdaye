# 压缩包分析与验收口径

本模块从 SC-IMG 1.0.0 的 30 个文件展开。启动与风格档案契约沿用原规范。其上增加 erdaye 仓库的入口、信息图形交接和案例，运行正文的 SHA-256 由同目录 manifest 记录。生成规范中的字段名与数值和文案约定可跨入口复用。

## 从附件到运行结构

| 附件依据 | 保留的方法 | 实现取舍 |
|---|---|---|
| 《03 视觉语言基础》《04 光线·色彩·构图语言》《05 风格材质与 Prompt 语言》 | 从所见到观看作用和叙事解释，光色形质往返校验 | 档案给每条结论留参考、区域和证据类型。 |
| 《08 结构性叙事表达》《09 AI 插画与分镜设计》及 M5 Word 讲义 | 张力、路径、停留点，六字段和系列风格锚点 | 六字段面向任务编译，帧内焦点与跨帧识别各自核查。 |
| 《AI视觉风格克隆体系说明文档_VSCF》 | 十三个独立观察系统 | 完成度、边缘、信息密度各有档案位置。尺寸占比等原文示例依具体参考启用。 |
| 《风格克隆系统》SC-IMG | 一个识别核心、五类十三项、证据、可变性、三记录、六维验收 | 扩展显式主题操作、统一双语规范和记忆加载状态。档案、任务、生成与实际验收可分别版本化。 |

压缩包随附的风格案例来自教学用假想参考描述，用于结构和提示导出验算。真实目标风格的精度需要实际参考图、可比较的新题材输出与成图验收。

## 包内各部分如何工作

| 文件层级 | 数据用途与验收 |
|---|---|
| SYSTEM 与 manifest | 模型从明确入口读取完整正文和规范版本。打开仓库首页时，README 把模型或读者导向 07。 |
| 风格档案与主题任务 | 风格档案绑定参考与规则，主题任务绑定实际内容、锁定和交付。换题材用新任务引用同一档案版本。 |
| render_spec 与导出器 | 同一个条款 ID 配两种语言的内容，并引用风格规则与项目锁定。JSON 从该数据逐项导出，中文简版保留必须条款，共享规格和准确文案进入四份提示。 |
| 成图验收与系列档案 | 独立记录实际提交、模型、产物、单图要求和系列一致性。验收可从内容、编码、风格和实际输出回推。 |
| 仓库联动 | 02 负责案例与来源，06 负责数据、叙事和编码，07 处理风格与适配。借用 01、03、04、05 的方法时，以来源定义锁定其含义。 |

实际联动示例使用库内 CASE-0002 的资料作内容依据，并使用包里的教学风格档案作表现依据。五个阶段标题经已有案例转录，局部回返来自图面推断，圆形像素尺寸属于图像测量。在任务中分别写明。 [项目交接](./00-仓库联动说明.md) · [CASE-0002 联动示例](./examples/CASE-0002-联动示例.md)

## 经常发生的三类失配

1. **规则把旧物料写死。** 复查把原物料换掉是否仍能产生同一视觉关系。把偶然位置、对象、色号或构图作为可变或项目限定项记录。
2. **主题替换牵动阅读关系。** 锚点承担对象改变时重查光、边缘、疏密和画面节奏。动作改变时复查接触、道具、遮挡和空间。
3. **四版文字逐步漂移。** 共用结构化规格与成对的中英文条款。简版从已审核的 must 条款提取。图片内的精确文案作为共享原值。

## 验收矩阵

| 测试 | 建议检查 |
|---|---|
| 同题变体 | 核心风格可辨，新动作或镜头真实变化。 |
| 相邻主题扩展 | 角色、资产和环境分别使用适用条件，媒介和视觉关系仍可辨。 |
| 跨题材 | 风格核心有新承担对象。检查旧参考的特定身份和道具有无被无关继承。 |
| 视觉对照 | 保持题材，移除一条候选核心后观察识别变化。 |
| 四版提示 | 对照 ID、主体、数值、文字、条件和作用范围。JSON 可解析与实际模型执行分别检查。 |
| 成图 | 按六维填写可见证据。记录未生成、未审、待定及通过条件。 |

通用性体现为哪些关系能跨题材成立，以及适用边界能否复查。风格档案的版本、后端真实输入和成品一起保存，便于复用同一条件或解释差异。

程序验证覆盖结构、槽位、规则映射、强制条款、文案原值与规格。译文是否准确表达关系要比对双语条款，画风和信息是否实际保持要看成图。联动实例附未生成状态的验收记录。
