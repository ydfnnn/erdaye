# 风格系统与信息图形工作流

07 将参考里的视觉关系迁移到已经定义的信息任务。它接收数据、组织逻辑、叙事和编码目标，把需要保持的内容映射为项目锁定，再将可迁移风格写入一份生成规范和四版提示词。

## 从哪里取输入

| 仓库层级 | 07 读取或接收什么 | 迁移中怎样使用 |
|---|---|---|
| [01 信息图形数据逻辑](../01-信息图形数据逻辑/) | 五种组织逻辑中的主归属及其关系。 | 锁定被表达的顺序、层级、分类归属、检索键或空间定位。可以调整构图以实现同一关系。 |
| [02 类型案例](../02-信息图形类型案例/README.md) | CASE、表现标签、原图或可访问来源、数据、分析证据。 | 给材料指定风格、内容或版式用途。数量或文字从基础表和字典获取，图面观察与推断各有证据。 |
| [03 ISOTYPE](../03-ISOTYPE信息图/README.md) | 用到定量图符时采用图符单位、重复数量与取整规则。 | 统一单位与图例。线形、材质可适配，定义了数值的图符数量、等单位关系和拆分约定需核对。 |
| [04 统计图形分析](../04-统计图形分析/README.md) | 使用统计图形时由数据和项目确认字段、计算与编码。 | 锁定有效的聚合、单位、刻度与数据通道。风格影响背景、字体、装饰或图层样式。 |
| [05 Gestalt 视觉组织](../05-Gestalt视觉组织原则/README.md) | 分组、路径、连接、图底等可比较的组织依据。 | 用距离、连接或对比辅助读出原关系。若色形承担分组含义，改变前核对类别区分及图例。 |
| [06 主题信息图形设计](../06-XXX主题信息图形设计/README.md) | 阶段 04 基础表和字典、05 叙事方案、06 视觉编码矩阵。 | 在设计实验中调用 07。将档案版本、编码映射、四版提示和实际候选送入阶段 08 校验与交付。 |

仓库级 07 的职责是风格分析与迁移。06 项目内的阶段 07 文档记录信息轮盘测试的定义状态。  [信息轮盘测试](../06-XXX主题信息图形设计/07-信息轮盘测试/README.md)

## 把 06 的记录交给 07

1. **确定构图之前要保住的信息。** 从 06 的叙事命题确定读者要看懂的关系，列出涉及的字段、源文件、可追溯版本与归类。注明哪些是转录、计算、图面推断或待确认。
2. **写字段到画面的映射。** 对每条重要信息写出字段或关系、载体、校验方式。例如用位置与箭头表示已确认的先后；用固定长度单位表示量；用文字作为类别标签。附上原始图例和准确文案。
3. **明确哪些表现可改。** 纸感、阴影处理、边缘、字形、画面语气可以通过风格档案迁移。若一种配色、形状或比例在当前图中承担数据含义，把它与校验依据列入项目锁定。项目可采用多条承载同一关系的编码，例如颜色加线型，提高可读性。
4. **产出可回查的提示。** 在 image_task 的 project_locks 记录锁定 ID；在 render_spec 的对应 must 条款引用同一 ID。准确文字与规格还用共享结构化字段保存。四版提示都可据这些 ID 回查。
5. **验收和回写。** 阶段 08 先比对源表、图例与图中数据，再核对风格证据、文字和可读性。若进入 02 案例库，附合法可引用的原图来源、数据集、字典、分析和风格版本，按原案例规范回写。

[交接字段模板](./templates/infographic-context.template.json)可作为 image_task 的 infographic_context 附加记录。path 使用仓库根目录相对路径，source_revision 填核对数据时的提交。data_boundaries 简述数据证据，例如转录、计算、图面推断、待确认或新设计选择。基础表和数据字典保存在各自目录。交接字段用于溯源，导出器以 project_locks、共享文案与实际生成条款为校验依据。 [06 叙事框架](../06-XXX主题信息图形设计/05-叙事框架搭建/README.md) · [06 视觉编码](../06-XXX主题信息图形设计/06-视觉编码/README.md) · [06 设计实施](../06-XXX主题信息图形设计/08-设计实施/README.md)

## 什么时候先改方案

| 情况 | 处理 |
|---|---|
| 参考图把最大的面积给装饰，当前图让面积承载量值 | 保持数量映射，把风格里的疏密、边缘或纹理转到独立装饰区。 |
| 参考图只有单一视觉焦点，当前项目有多个必读节点 | 将重点安置在标题或入口，保护各信息节点的标签和主线连贯性。 |
| 参考的相近色会削弱类别辨认或文字对比 | 调整明度、标记形状、线型或字形。在输出中复查读者能否按图例识别。 |
| 图面能读出阶段或反馈，但无时间或因果依据 | 按记录呈现顺序，用辅助线表达已标记的示意反馈；保留推断状态。 |
| 任务含精确坐标、数值、文字或产品几何 | 可先用确定性数据绘图和排版标出精确信息，再应用风格或组合图层，从实际产物逐项核查。 |
